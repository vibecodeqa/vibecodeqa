commit, edition, or URL named in that report.

## Method

These reports follow the [Assessment Criteria](../assessment.md). The assessor must review
evidence before scoring and must treat self-reported scores as claims to verify, not
authoritative results. The stack page reports score only the linked stack page; rubric,
composition, registry, and reference repo evidence is supporting context unless a report
states a separate target and score.
